# canvas-design

Create stunning visual art in PNG and PDF formats using professional design philosophy. Use this workflow when creating posters, marketing materials, social media graphics, or any static visual design.

## When to Use

- Creating product posters
- Designing marketing materials
- Social media graphics
- Brand visuals
- Print materials
- Event posters

## How to Use This Workflow

### Step 1: Read the Skill Documentation

```bash
# View the skill instructions
cat "C:\Users\china\.agent\skills\canvas-design\SKILL.md"
```

Or use the view_file tool to read the SKILL.md file.

### Step 2: Understand User Requirements

Extract key information:
- **Purpose**: What is the design for? (poster, social media, print)
- **Content**: What text/images should be included?
- **Style**: Modern, minimal, elegant, bold, playful?
- **Brand**: Any brand colors or guidelines?
- **Size**: Standard poster, Instagram post, A4 print, etc.

### Step 3: Apply Design Principles

Follow modern design best practices:
- **Visual Hierarchy**: Most important elements first
- **Color Harmony**: Use complementary or analogous colors
- **Typography**: Maximum 2-3 fonts, clear hierarchy
- **White Space**: Don't overcrowd, let design breathe
- **Alignment**: Everything should align to a grid
- **Contrast**: Ensure text is readable

### Step 4: Generate the Design

Use the generate_image tool to create the visual:

```

with [color scheme], [layout description], professional quality, 
high resolution, [specific details]"
```

**Example:**
```

gold frame on soft beige background, minimalist style, with warm 
earth tones (beige, gold, cream), centered composition, professional 
photography quality, high resolution, soft shadows, premium feel"
```

### Step 5: Iterate and Refine

- Review the generated design
- Adjust colors, layout, or elements as needed
- Ensure brand consistency
- Check readability and visual impact

## Design Best Practices

### Color Schemes for KovaScape

**Elegant/Premium:**
- Beige + Gold + Cream
- Navy + Gold + White
- Charcoal + Rose Gold + Ivory

**Modern/Fresh:**
- White + Black + Sage Green
- Light Gray + Teal + White
- Cream + Terracotta + Olive

### Typography Guidelines

**For Posters:**
- Headline: 48-72pt, bold or elegant serif
- Subheading: 24-36pt, medium weight
- Body text: 14-18pt, regular weight

**Font Pairings:**
- Playfair Display (serif) + Inter (sans-serif)
- Cormorant (serif) + Montserrat (sans-serif)
- Libre Baskerville (serif) + Open Sans (sans-serif)

### Layout Principles

1. **Rule of Thirds**: Place key elements at intersection points
2. **Visual Balance**: Distribute visual weight evenly
3. **Focal Point**: One clear main element
4. **Breathing Room**: 10-15% margins minimum
5. **Alignment**: Use grid system

## Common Design Types

### Product Poster
- Hero product image (60-70% of space)
- Brand name (top or bottom)
- Key features (3-5 bullet points)
- Call-to-action (optional)

### Social Media Graphic
- Square format (1080x1080) or vertical (1080x1350)
- Bold headline
- Supporting visual
- Brand logo
- Minimal text

### Marketing Material
- Clear value proposition
- Supporting imagery
- Brand elements
- Contact/CTA information

## Pre-Delivery Checklist

Before finalizing the design:

- [ ] Brand colors are accurate
- [ ] Text is readable at all sizes
- [ ] Visual hierarchy is clear
- [ ] Design works in both color and grayscale
- [ ] All text is spelled correctly
- [ ] Image resolution is appropriate (300 DPI for print, 72 DPI for web)
- [ ] File format is correct (PNG for web, PDF for print)
- [ ] Design aligns with brand guidelines

## Tips for Better Results

1. **Be Specific**: Detailed prompts = better results
2. **Reference Styles**: Mention specific design styles or movements
3. **Color Codes**: Use hex codes for precise colors
4. **Iterate**: Generate multiple versions and refine
5. **Context**: Consider where the design will be used
6. **Simplicity**: Less is often more in design

## KovaScape-Specific Guidelines

For KovaScape brand designs:

**Brand Personality:**
- Elegant yet accessible
- Modern with classic touches
- Premium but not pretentious
- Warm and inviting

**Visual Style:**
- Clean, uncluttered layouts
- Natural materials and textures
- Soft, warm lighting

**Color Preferences:**
- Warm neutrals (beige, cream, taupe)
- Accent colors (gold, sage green, soft blue)

**Typography:**
- Elegant serifs for headlines
- Clean sans-serifs for body
- Avoid: Overly decorative or trendy fonts
