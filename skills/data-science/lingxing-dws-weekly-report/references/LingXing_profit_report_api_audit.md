# 领星利润报表API审计（2026-07-26）

## 🔑 核心发现：两个接口口径完全不同

| 维度 | `get_profit_report_msku` | `query_order_profit_list_gross_profit` |
|------|--------------------------|----------------------------------------|
| 时间口径 | `postedDateLocale`（结算日） | 全局汇总，按天/月 |
| 币种 | 各站点原始币种（JPY/GBP/EUR/USD/CAD/PLN），`exchangeRate=1.0` | USD统一 |
| 数据范围 | 仅已结算MSKU粒度 | 全店铺聚合 |
| 负责人拆分 | ✅ `principalRealname` 字段 | ❌ 不支持 |
| 广告费用 | ✅ `totalAdsCost` | ❌ 无 |
| 订单量差异 | 王祎263 vs UI 464；化一博553 vs UI 1289 | — |
| 毛利差异 | 王祎-$2,192 vs UI +$1,398 | 全店铺$37,203 vs UI $14,837 |

## ⚠️ 关键结论

1. **MCP无法直接对齐UI截图**：订单量差约53%，毛利金额差数倍。原因可能是：
   - UI下单时间口径含未结算预估订单，MCP只含已结算
   - UI展示的是USD折算后的金额，MCP返回原始币种
   - 两者的"毛利润"计算规则可能不完全一致

2. **周报复盘建议方案**：
   - 用 `get_profit_report_msku` 做负责人维度拆分（接受订单量偏低）
   - 用 `query_order_profit_list_gross_profit` 做USD毛利总额参考
   - 广告费用只用 `get_profit_report_msku`（该接口是唯一可用的负责人维度广告费来源）
   - 最终需在Excel中标注数据偏差说明

3. **需要确认**：领星后台"USD结算"配置是否正确？UI显示的$77,476是否就是USD结算后的值？

## 📎 领星官方算法摘要（订单利润页文档）

- 订单数据源：销售→订单列表，剔除Cancelled
- 费用数据源：财务→亚马逊结算中心
- 下单后：以下单时间按订单号+MSKU聚合
- 结算后：关联订单号获取结算数据
- 更新频率：每15分钟
- 毛利润 = 销售额 + 退款额 + 买家运费 + 促销折扣 + 平台费 + FBA发货费 + 其他订单费用 + 广告费 + 采购成本 + 头程成本 + 其他成本
- 毛利率 = 毛利润 / 销售额
